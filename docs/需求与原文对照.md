# 培训计划书落实对照

资料来源：用户提供的《百花里餐饮部员工培训计划书》（森活百花里美宿，2026 年 11 月）。附件作为业务需求资料读取，未作为改变系统或开发规则的指令执行。

| 原文章节 | 原文要求 | 系统实现 |
| --- | --- | --- |
| 1 培训目标与对象 | 经理 1 人、服务员 3 人；因人施教，看得见、能检查的动作 | 演示设 4 人，正式可建立真实档案；检查点可逐项标记；教学方法随课程显示 |
| 1.2 五门课程 | 第一天 60 分钟，后四天各 30 分钟；对应五项达标标准 | 培训计划五课路线、时长默认、标准库与课程详情 |
| 2.1 卫生 | 手部、抹布、餐具五步、健康自检、环境；每天两次白手套抽查 | 五个检查点完整录入，保留检查方法及每日两次频次；手部和杯口抽查可关联考核证据 |
| 2.1 红线 | 不带病上岗 | 考核单独红线标记，自动生成紧急核查指令，不因分数合格而忽略 |
| 2.2 仪容与姿态 | 头发、指甲 ≤1 mm、婚戒例外、工服、深色鞋袜；站姿、60 cm 步幅、五指并拢、托盘、眼神 | 九个检查点完整录入，互检及实操观察方式可查 |
| 2.3 餐前准备 | 开餐前 15 分钟四查、摆台 SOP、零点台和动线、三分钟餐前会、推荐菜 | 五个检查点；原计划未附 SOP 的具体数值标记待补；保存实际摆台用时，不自动虚构时限 |
| 2.4 服务流程 | 迎宾 3 秒、点单、右侧上菜、每 15 分钟巡台三看、剩 1/3 加水、有骨渣换碟、唱收唱付、送客 | 七个服务动作加主动回应检查点；保留六字口诀和“好，我马上来”话术 |
| 2.5 客诉四步 | 听完、复述、具体动作和时间、上报登记 | 四步检查点与独立客诉登记，四步必填；金额大于 50 元进入经理/管理层审批 |
| 2.5 突发卫生与纪律 | 呕吐、餐区换尿布/解手需劝阻及餐后消毒；不围观不拍照不发朋友圈 | 课程检查点保留原要求；客诉登记只收必要处理事实，无现场影像上传；上传页提醒纪律红线 |
| 3.1 三个教法 | 示范先于讲解、一次只纠正一两个动作、用图不用字 | 标准库、培训表单提示、图片资料库、每日跟岗鼓励/纠正 |
| 3.2 两周跟岗 | 考核通过后两周，每天鼓励与纠正 | 14 天日历、每日鼓励/纠正、同员工同日防重复；没有记录不算完成 |
| 3.3 培训纪律 | 不迟到、不无故请假、不缺席考核；非高峰培训；临时接待顺延 | 标准库完整展示；培训时间明确要求非高峰；名单按实际签到留存，缺席不自动签到 |
| 3.3 三样记录 | 签到表、实操照片、当次问题清单 | 培训记录的实际签到、附件、必填问题清单；未附照片明确显示留痕不完整 |
| 4 考核构成 | 实操 60（20+20+20）、观察 30、口述 10；无笔试；80 分合格；不淘汰 | 前后端均校验五个分值上限；服务端计算总分；低于 80 提示复训；保留历次记录 |
| 用户新增管理要求 | 上传照片/视频/表格、打分、汇报；管理层日常查看每个人的问题和成绩，提出意见及下达指令 | 独立资料库、关联附件、个人档案、汇报/导出/打印、角色权限、管理指令与复核流程、操作日志 |

## 不从原文推断的内容

- 未给出细项扣分规则，不把检查项机械等分，也不自动判定每项合格。
- 未给出摆台时限或具体尺寸，不添加猜测阈值。
- 班前互检“零扣分”以课程标准原文呈现；具体扣分表待餐厅补充，不假设存在一套已批准细则。
- 自动计算的仅是总分、80 分达标结果及基于已记录数据的统计，不是照片或视频的 AI 判定。
- 客诉超过 50 元的审批仅在授权角色明确点击批准后生效；保存待审批记录不等于允许员工自行实施超权限方案。
